## 📌 Brèves (versions écrites / captions)

1. **HyperFrames — la vidéo qui se code en HTML.** HeyGen a publié en open source (Apache 2.0) HyperFrames, ~46,3k étoiles : un moteur qui transforme HTML/CSS, médias et animations (GSAP, Lottie, Three.js, WAAPI) en MP4 **déterministe** via Chrome headless + FFmpeg. CLI, studio navigateur, rendu distribué sur AWS Lambda. Argument-clé : contrairement aux modèles vidéo probabilistes facturés au crédit, un même fichier re-rend exactement la même vidéo — reproductible, versionnable, pilotable par un agent.
2. **context-mode — 98 % de contexte en moins.** mksglu, ~20,9k étoiles (licence ELv2) : optimisation de la fenêtre de contexte pour agents de code. Il met les sorties d'outils en bac à sable (315 Ko → 5,4 Ko, soit 98 % de réduction), persiste la mémoire de session en SQLite/FTS5, et impose un routage sur 17 plateformes via MCP + hooks. Il pousse l'agent à écrire des scripts d'analyse plutôt qu'à charger des fichiers entiers en contexte.
3. **marketingskills — le playbook d'un consultant, en git clone.** Corey Haines (fondateur de Conversion Factory), seul, ~48,2k étoiles : « Marketing skills for Claude Code and AI agents ». 60+ compétences pour agents — CRO, copywriting, SEO (audit, programmatique, schema), ads, analytics, A/B testing, rétention, pricing. Compatible Claude Code, Cursor, Windsurf via la spec Agent Skills. Le savoir-faire d'un expert marketing devient une bibliothèque que ton agent exécute.
4. **GPT-6 Astra — 100 % sur ExploitBench.** Sorti le 3 septembre (fenêtre de contexte 1,05M tokens), le dernier modèle d'OpenAI sature ExploitBench — transformer une faille connue en exploit fonctionnel — à **100 %**, contre 78,5 % pour GPT-5.6 Sol et 70 % pour Fable 5.1 (Anthropic). Il signe aussi les meilleurs scores publiés par OpenAI en raisonnement abstrait et maths. La capacité offensive automatisée franchit un cap ; le durcissement défensif doit suivre au même rythme.
5. **Lightpanda — le navigateur réécrit pour les agents.** lightpanda-io/browser, ~34,9k étoiles, écrit **de zéro en Zig** (ni fork Chromium, ni patch WebKit) : headless pensé pour l'automatisation et les agents (mode agent natif, serveur MCP). Bench sur AWS m5.large, 933 pages réelles : ~123 Mo de RAM pour 100 pages contre ~2 Go pour Chrome (≈16×), et 5 s d'exécution contre 46 s (≈9×). Exécution JS réelle, pas un simple client HTTP.
6. **EU AI Act — article 50 en vigueur.** Depuis le 2 août 2026, les autorités (AI Office + national) appliquent les obligations de transparence de l'article 50 : tout « déployeur » utilisant un système d'IA en contexte professionnel doit étiqueter le contenu généré ou manipulé — texte présenté comme humain, images de synthèse, deepfakes, audio/vidéo IA — sous peine de sanctions. Conséquence directe pour tout créateur qui publie de l'IA : le marquage devient une obligation légale, pas une option.
