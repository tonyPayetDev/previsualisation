## 📌 Brèves (versions écrites / captions)

1. **debpalash/VoiceStudio — l'alternative locale à ElevenLabs (gisement A/B, dépôt qui explose + génération média).** `debpalash/VoiceStudio`, **Python**, **~71,4k étoiles (+2 301 sur la journée, top mover du jour)** au 17 octobre (GitHub Trending). Présenté comme *« the open-source, fully-local ElevenLabs alternative »* : **clonage de voix, voice design, doublage vidéo calé dans le temps, dictée (widget flottant), transcription, création d'audiobooks**, en **646 langues**. Tourne **en local** sur GPU NVIDIA (CUDA), Apple Silicon (Metal) ou CPU ; services distants optionnels. Expose une **API locale + MCP pour agents**, des recettes réutilisables et des watch folders. *Angle / parti pris : la voix de synthèse était une facture mensuelle chez un prestataire cloud ; elle redevient un logiciel qu'on installe et qui tourne sur sa propre machine, dans presque toutes les langues — ta voix (et ta donnée) t'appartient à nouveau.*

2. **xerj-org/xerj — un moteur de recherche compatible Elasticsearch en un binaire (gisement A, dépôt qui explose).** `xerj-org/xerj`, **Rust**, **~7,0k étoiles (+1 648 sur la journée)** au 17 octobre (GitHub Trending). `xerj autoindex` indexe automatiquement n'importe quel dossier pour que les agents récupèrent le bon bout de code au lieu de lire fichier par fichier. **Implémente l'API REST Elasticsearch** (les clients existants s'y branchent) ; *« not a reimplementation of Elasticsearch internals, not a fork »*. **Binaire statique unique, sans JVM** ; combine **plein-texte + vecteur + hybride dans un seul moteur** (pas de base vectorielle séparée). Indexe code (tree-sitter, symboles + lignes), CSV/JSON/XML/YAML/SQLite, PDF/DOCX/PPTX/XLSX, EPUB, notebooks, logs, e-mails, projets Unity. Benchmarks maison vs **Elasticsearch 8.13.4 : 55 victoires, 26 égalités, 4 défaites** (défaites = p99 lecture sous charge d'écriture lourde). *Angle / parti pris : le moteur de recherche d'entreprise, c'était un cluster Java à administrer plus une base vectorielle à côté ; là c'est un seul fichier Rust qu'on lance — la pile de recherche à deux étages, tu peux l'éteindre.*

3. **affaan-m/ECC — le harnais d'agent d'un seul mainteneur passe 281k étoiles (gisement A, quelqu'un a construit un truc).** `affaan-m/ECC`, **licence MIT**, JavaScript, **~281,6k étoiles (+1 057 sur la journée)** au 17 octobre (GitHub Trending). *« The agent harness performance optimization system »* : skills, instincts, mémoire, sécurité, dev « research-first » pour **Claude Code, Codex, OpenCode, Cursor**. Revendique **71 agents, 311 compétences, 97 command shims** ; release **2.2.3 datée du 1er octobre 2026** ; **3 934 commits** ; *« a single maintainer »*, financé par sponsors + abonnés Pro. L'agent *« planifie avant de construire, vérifie par des tests, se relit depuis un contexte neuf, retient ce qui compte et transforme les wins répétés en compétences réutilisables »*. *(NB honnête : aucun benchmark chiffré sur la page — le « performance optimization » reste une revendication, pas une mesure.)* *Angle / parti pris : l'« organisation d'ingénierie senior » — process, revues, mémoire institutionnelle — n'est plus une boîte qu'on recrute, c'est le dossier de config d'un inconnu, et il a plus d'étoiles que la quasi-totalité des repos de startups financées.*

4. **MadsLorentzen/ai-job-search — la recherche d'emploi comme framework Claude Code (gisement A, quelqu'un a construit un truc).** `MadsLorentzen/ai-job-search`, **Python**, **~48,6k étoiles (+898 sur la journée)** au 17 octobre (GitHub Trending). Framework bâti sur **Claude Code** pour **évaluer les offres d'emploi** (noter la pertinence d'une annonce) et **adapter le CV** poste par poste. *Angle / parti pris : le travail de tri d'un chasseur de têtes — lire les annonces, filtrer, ajuster le dossier à chaque offre — tient dans une commande qu'on lance en français ; ce n'est pas un SaaS de plus, c'est un dossier qu'on clone et qui postule à ta place.*

5. **anthropics/claude-plugins-official — Anthropic ouvre le répertoire officiel des plugins (gisement C, produit / écosystème).** `anthropics/claude-plugins-official`, **Python**, **~40,7k étoiles (+1 552 sur la journée)** au 17 octobre (GitHub Trending). Répertoire **officiel, maintenu par Anthropic**, des plugins Claude Code. *Angle / parti pris : après des mois de configs solo qui explosent (Superpowers, ECC, agency-agents…), l'éditeur reprend la main et cadre le marché — rayon, mainteneur, validation ; la ruée désordonnée vers les agents vient de se doter d'un supermarché officiel, ce qui enterre les bricolages non packagés et assied celui qui tient l'étagère.*
