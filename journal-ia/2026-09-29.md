## 📌 Brèves (versions écrites / captions)

1. **VoiceStudio — l'alternative locale et gratuite à ElevenLabs.** Dépôt debpalash/VoiceStudio, ~44,5 k étoiles (~+3 086 en 24 h le 28 septembre) : « the open-source, fully-local ElevenLabs alternative ». Clonage de voix, voice design, doublage vidéo, dictée (widget flottant), transcription, production de livres audio en batch, 646 langues, API locale + MCP pour agents, workers distants optionnels. Licence AGPL-3.0, tout tourne sur ta machine (contrôle privacy total). Angle : le studio de voix off / doublage à l'abonnement perd sa raison d'être quand ta voix se clone et se traduit gratuitement, hors-ligne.
2. **pdoom-video — un clip musical rendu par du code, en deux prompts.** Dépôt mexicat/pdoom-video : clip génératif, karaoké typographique synchronisé au mot, pour la chanson « I'm Upping My P(doom) » (version « Claude-Pop », Suno, septembre 2026). Concept, découpage lyrique, analyse audio, renderer et toutes les scènes produits en conversation avec Claude (Opus 5.5) dans Claude Code — deux générations, aucune idée de scène imposée, rendu via HTML/Canvas/FFmpeg. Devenu viral. Angle : le motion design et le montage d'un clip se réduisent à un dépôt qui se compile.
3. **Paperclip — gérer les agents IA comme une entreprise.** Dépôt paperclipai/paperclip, ~93 k étoiles (~+2 401 en 24 h le 28 septembre) : « the app people use to manage AI agents for work », orchestration de flottes d'agents. Tâches en tickets, conversations en fils, sessions persistantes après reboot ; org charts, délégation, gouvernance ; budgets avec throttling (l'agent se met en pause quand le budget explose) ; approval gates, execution policies, audit logging complet ; alignement par « task ancestry » (l'agent sait le pourquoi, pas seulement le quoi). Angle : le management intermédiaire — organigramme, budget, contrôle — appliqué à une main-d'œuvre logicielle avant qu'elle ne génère un revenu.
4. **magpie — n'importe quel agent sur n'importe quel modèle.** Dépôt yetone/magpie, ~1 358 étoiles (recensé le 28 septembre parmi les tendances du jour). Un écran / une icône dans la barre de menu qui liste chaque agent installé et le modèle auquel il est réglé ; un clic change le modèle. Passerelle locale parlant OpenAI Chat Completions, OpenAI Responses et Anthropic Messages, qui redirige vers le vendeur servant le modèle : « Codex on DeepSeek, Claude Code on Kimi, Gemini CLI on GLM ». Angle : l'agent est découplé du modèle de son éditeur — tu gardes l'outil et choisis le fournisseur le moins cher.
5. **golive-skill — mettre en ligne le produit bâti par l'agent.** Dépôt mikehasa/golive-skill (alpha 0.1.0, recensé le 28 septembre, ~1 021 étoiles) : Agent Skill + CLI Node zéro-dépendance qui détecte, planifie, fait approuver, applique et vérifie la mise en production — sur tes propres comptes, sans backend ni télémétrie golive. Couvre l'hébergement (Vercel, Netlify), la base (Supabase, Neon), le DNS domaine (Porkbun, GoDaddy), l'email transactionnel (Resend), les paiements en test (Stripe) et l'auth Supabase, plus la désinstallation. Angle : la mise en prod, tâche facturée à la journée par un devops, tient dans une compétence qu'on installe.
6. **SWE-bench Pro — le fossé open / fermé sur le génie logiciel.** Sur le classement SWE-bench Pro (Scale, jeu public standardisé), le leader atteint ~61,5 % (jeu commercial propriétaire ~51,5 %), devant le précédent fleuron (~59,1 % / ~47,1 %) ; le meilleur poids ouvert plafonne à ~38,7 %. Écart d'environ 22 points entre le meilleur payant et le meilleur open sur des tâches d'ingénierie longues. Angle (benchmark, sans nommer le modèle) : à rebours du récit « l'open rattrape », sur le vrai code d'ingénierie le poids ouvert reste largement derrière. NB : versions de benchmark variables d'un labo à l'autre — comparaison indicative.
