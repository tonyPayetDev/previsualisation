## 📌 Brèves (versions écrites / captions)

1. **DeepSeek Harness — le harnais, pas le modèle, bat le record d'étoiles de GitHub (gisement A).** Le **13 août 2026**, DeepSeek a open-sourcé `deepseek-harness` : **~50 000 étoiles en 12 h**, **~92 000 à la 28ᵉ heure** (plus de 2 100 étoiles/heure), démarrage que la presse tech a qualifié de **plus rapide jamais enregistré** sur GitHub — **141 532 étoiles au 17 août**, **près de 190 000** désormais. L'idée radicale : *« everything is a plugin »* — l'adaptateur de modèle, le registre d'outils, le journal de session, le sandbox et **la boucle d'agent elle-même** sont des plugins. Angle / parti pris : un labo de modèles ne se bat plus sur le modèle mais sur le **harnais** (le runtime autour) ; DeepSeek le donne gratuitement pour concurrencer Claude Code — le fossé change de camp.

2. **Ox Alpha — un modèle de code anonyme, gratuit, qui grimpe puis dégonfle (gisement C).** Apparu **le 20 août 2026** sur OpenRouter (aussi OpenCode Zen, Mercury Cloud), **Ox Alpha** est un modèle *stealth* gratuit : **contexte 1 048 576 tokens**, entrée texte/image/vidéo, tool-calling. En tests indépendants précoces : **80 % sur DeepSWE**, devant Claude Fable 5 (65 %) et GPT-5.6-sol (52 %) — mais sur **le jeu complet**, il revient **à peu près au niveau de GPT-5.6-sol** (petit échantillon = forte variance). **Personne n'en revendique la paternité** ; SiliconANGLE (23 août) : « nobody knows who built Ox Alpha or where the code goes ». Angle : l'écart mesuré se dégonfle à l'épreuve du banc complet ; et un modèle gratuit + anonyme, tu le paies avec ton code, envoyé vers un serveur inconnu.

3. **Anthropic — computer use, browser use, Skills et Files passent en GA (gisement A/C).** Le **20 août 2026**, Anthropic a fait passer en **disponibilité générale** sur la plateforme Claude : *computer use*, le nouvel outil *browser use*, l'**API Skills** et l'**API Files**. La combinaison réunit les quatre étapes qu'une agence assemblait séparément : **opérer un logiciel, naviguer une appli web, appliquer une méthode réutilisable (Skill), et renvoyer un fichier fini**. Angle : le workflow d'agent complet cesse d'être un bricolage de bouts recollés ; il devient une chaîne unique — de quoi packager une tâche métier de bout en bout.

4. **A2A rejoint l'Agentic AI Foundation (Linux Foundation) (gisement C).** Annoncé **le 20 août 2026** : le protocole **A2A** (agent-à-agent) de Google rejoint l'**AAIF**, dirigée par la Linux Foundation, aux côtés du **MCP** d'Anthropic (projet fondateur). La fondation est passée de **49 à plus de 250 membres** en moins d'un an (AWS, Anthropic, Block, Bloomberg, Cloudflare, Google, Microsoft, OpenAI…). MCP couvre l'intégration agent↔outils ; A2A, la communication entre agents. Angle : les deux protocoles rivaux sous un même toit neutre = interopérabilité par défaut, moins de lock-in propriétaire — la « plomberie » de l'économie des agents se standardise.

5. **Hugging Face explore une vente à 13 Md$ (gisement D — argent).** Rapporté **les 23–24 août 2026** (TechCrunch, The Information/Reuters) : Hugging Face aurait mandaté une banque pour sonder des acquéreurs, à une valorisation de **13 Md$ ou plus** — près du **triple** des 4,5 Md$ de sa série D (2023). Aucun acheteur identifié, discussions préliminaires. La librairie **Transformers s'installe plus de 3 millions de fois par jour** (1,2 Md d'installs cumulées). Angle / parti pris : le **dépôt commun** de l'IA open — celui sur lequel tout le monde construit — pourrait passer sous le contrôle d'un seul propriétaire ; racheter Hugging Face risque de détruire ce qui fait sa valeur (sa neutralité).

6. **AWS — la recherche web des agents s'étend, sans egress de données (gisement A/C).** En **août 2026**, **Web Search sur Amazon Bedrock AgentCore** (GA depuis juin) s'étend à l'**Europe (Irlande)** et l'**Asie-Pacifique (Tokyo)**, et ajoute le **filtrage par domaine et par plage de dates** (jusqu'à 100 domaines par liste, allowlist au niveau gateway). Outil **entièrement managé**, résultats **cités**, **zéro sortie de données** hors du compte AWS du client ; **7 $ / 1 000 requêtes**. Angle : les agents gagnent une recherche web sourçable et cloisonnée — être curieux du web sans exfiltrer les données de l'entreprise.
