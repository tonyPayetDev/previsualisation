## 📌 Brèves (versions écrites / captions)

1. **PRAXIST — un système de recherche autonome, mais « source ouverte » à géométrie variable (gisement A).** `sapientinc/PRAXIST` affiche **~5 500 étoiles** (5 458 vérifiées), pour un dépôt **créé le 27 août 2026** — soit l'essentiel de ses étoiles gagné en cinq jours. Signé de **Sapient** (l'équipe du *Hierarchical Reasoning Model*), il se présente comme *« an autonomous research system for measurable, computer-executable research »* : il **orchestre des agents en parallèle, évalue chaque piste de façon mesurable, et synthétise les résultats de génération en génération** sur des problèmes de recherche exécutables — pas du simple tuning de paramètres. Licence **Fair Source License 1.0** : *source-available*, gratuite sous **1 M$ de chiffre d'affaires**, payante au-delà. Angle / parti pris : après les harnais et les agents, on passe à **l'équipe de R&D qui s'auto-dirige** ; mais l'étiquette « source ouverte » recouvre une licence qui n'en est pas une — l'open-washing a trouvé sa formule juridique.

2. **Kimi Code CLI — l'agent de terminal qui prend une vidéo en entrée (gisement C, produit).** `MoonshotAI/kimi-code` (licence **MIT**) dépasse **~7 000 étoiles** (7,2k affichées) ; releases **0.34.0 (6 août)** puis **0.39.1 (28 août 2026)**, dépôt mis à jour le 31 août. Concurrent de Claude Code / Codex / Gemini CLI, sa singularité est l'**entrée vidéo native** : *« Drop a screen recording or demo clip into the chat and let the agent watch what is hard to describe in words — turn a reference clip into a LUT, a long video into a short, a screen recording into working code. »* Support ACP (Zed, JetBrains). Angle : au lieu de **décrire** un bug ou une maquette, tu **déposes l'enregistrement d'écran** et l'agent code d'après ce qu'il voit — le cahier des charges écrit cesse d'être le point de départ.

3. **Concat — le CapCut libre, 100 % local (gisement B, métier de Tony).** `jub0t/Concat` (licence **MPL-2.0**) affiche **931 étoiles**, dépôt **créé le 25 août 2026**. Il se décrit comme *« The free, open-source CapCut replacement »* : montage multipiste, transitions, TTS, contrôle de vitesse, **sous-titres automatiques via Whisper.cpp qui tournent entièrement sur la machine** (*« your audio never leaves it »*), **sans compte, sans filigrane, sans paywall**. Stack **Rust + React + Tauri + FFmpeg**, hors-ligne, multiplateforme. Angle (métier de Tony) : CapCut (ByteDance) — sous pression réglementaire aux États-Unis — gardait le montage **dans son cloud** ; un clone *local-first* rend l'abonnement, le filigrane et l'envoi de tes rushes optionnels.

4. **`codex-with-chatgpt` — ton abonnement ChatGPT en cerveau de planification, l'API en moins (gisement A, système partagé).** `XiaoDuoYa/codex-with-chatgpt` (licence **MIT**), dépôt **d'un seul développeur créé le 28 août 2026**, atteint **~1 900 étoiles** en trois jours. Le principe, résumé dans le README : *« ChatGPT thinks. Codex works. »* — il branche ton **abonnement ChatGPT Plus/Pro** (via un MCP en lecture seule sur ton workspace) sur la **planification et la relecture**, pendant que **Codex garde l'exécution** (edits, git, shell). Objectif : arrêter de **cramer des tokens d'API** sur le travail de réflexion, en le faisant avec un abo web déjà payé. Projet communautaire, non endossé par OpenAI. Angle / parti pris : c'est un **arbitrage** entre l'abo forfaitaire et le quota d'API facturé au jeton — la partie la plus chère de l'agent (penser, relire) passe sur une facture que tu règles déjà.

5. **Qwen3.8-Flash-Next — la même capacité pour un neuvième du coût d'entraînement (gisement C, modèle / prix).** `QwenLM/Qwen3.8-Flash-Next` (poids ouverts, ligne **News datée 2026-08-26 : *« We release Qwen3.8-Flash-Next »***) est un **MoE multimodal**, présenté comme **preview de l'architecture Qwen4** (attention hybride Gated DeltaNet + Qwen Sparse Attention, N-gram Embedding, optimiseur Muon) : **125 Md de paramètres** principaux **+ 51 Md** de N-gram embeddings, **6 Md activés par jeton**. Le claim central du README : *« training takes only about 1/9 as much [as Qwen3.7-Plus], yet it delivers superior capabilities in coding and office tasks. »* Angle / parti pris (moule « l'écart mesuré ») : la vraie bataille se déplace du **score brut** vers le **coût** — atteindre la génération précédente pour **~11 % de son budget d'entraînement**. Les scores détaillés sont sur le blog Qwen (non vérifié ici) ; le **1/9** vient de la fiche modèle.

6. **`sepia` — le « dé-IA » qui vise la charpente du texte, pas le vocabulaire (gisement A, système partagé).** `Nanako0129/sepia` (licence **MIT**) atteint **~1 300 étoiles**, dépôt **créé le 28 août 2026**. Sa thèse, citée dans le README d'après StoryScope : *« a classifier using narrative-structure features alone detects AI fiction at 93.2% macro-F1 »*, et **retoucher le style de surface n'y change presque rien** (95,5 % → 93,9 %). Sepia répare donc l'**architecture du récit** (arrêter d'expliciter le thème, relâcher les chaînes causales, varier les modes d'émotion) plutôt que la syntaxe ; modes *write / review / refactor / recreate*, compatible **77+ agents**. Angle / parti pris : la course détecteur-contre-humaniseur, longtemps jouée sur les **mots** (« delve », « tapestry »…), passe au **niveau structurel** — et rend obsolètes les « humaniseurs » de surface qui ne touchaient que la syntaxe.
