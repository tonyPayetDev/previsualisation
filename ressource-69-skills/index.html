Mode d'emploi

Comment installer une skill

Une skill, c'est juste un dossier avec un fichier SKILL.md dedans. Trois étapes, aucune exception.

  1. Clone (ou copie) le dossier de la skill dans .claude/skills/ à la racine de ton projet — ou dans ~/.claude/skills/ pour l'avoir partout.
  2. Vérifie qu'il contient bien un SKILL.md avec un name et une description en tête de fichier : c'est ça que Claude lit.
  3. Dans Claude Code, tape /nom-de-la-skill (par exemple /copywriting). Elle apparaît aussi toute seule quand ta demande correspond à sa description.
Exemple completterminal
mkdir -p .claude/skills
git clone https://github.com/kylezantos/design-motion-principles.git /tmp/dmp
cp -r /tmp/dmp/skills/design-motion-principles .claude/skills/
ls .claude/skills/design-motion-principles/SKILL.md
