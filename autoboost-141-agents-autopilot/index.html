Voix off

OpenAI vient de sortir un agent qui code un projet entier tout seul. En trente minutes, il génère des fichiers, des fonctions, une interface qui a l'air propre. Mais il y a un piège que personne ne montre. Dès que le projet dépasse quelques fichiers, l'agent perd le fil de l'architecture. Il réinvente des composants qui existent déjà ailleurs dans le code. Résultat : un projet fini en surface, à reprendre en profondeur avant de le livrer. Moi je pilote toujours à la main, avec Claude Code, agent par agent.
