Ce que c'est

La vidéo qui explique la machine derrière le Journal IA quotidien : une IA gratuite écrit l'édition la nuit, un script clone la voix, pose les sous-titres et publie sur 5 réseaux le matin. Montée avec le kit Reel Nexeus (reel-nexeus) : plein écran → split → cercle.
