Intégrer la page d'accueil dans WordPress

Koytcha Immo — marche à suivre, environ 20 minutes.

⬇ Télécharger la page complète (HTML)

Fichier autonome : toutes les images et polices pointent vers des adresses absolues. Ouvrez-le en double-cliquant dessus pour vérifier avant de l'intégrer.

Si le clic ouvre la page au lieu de la télécharger : clic droit → « Enregistrer la cible du lien sous… ». Ouvrir dans un onglet

Avant de commencer : faites une sauvegarde.

Une sauvegarde complète du site et de la base de données. Si un réglage tourne mal, c'est ce qui vous permet de revenir en arrière en cinq minutes au lieu de passer la journée dessus.

1Choisir la méthode

Deux voies, selon ce que vous voulez garder de l'existant.

MéthodeQuand la choisir
A — Modèle de page
recommandée		 La page reste du HTML/CSS pur. Rendu identique au pixel près, le plus rapide à charger. En revanche Florent ne pourra pas la modifier depuis Elementor.
B — Reconstruction Elementor Chaque section est refaite avec les widgets Elementor. Beaucoup plus long, et les effets (Ken Burns, néon au survol, miroir) demandent quand même du CSS personnalisé. À réserver au cas où l'équipe doit éditer la page elle-même au quotidien.

2Méthode A — poser un modèle de page

a. Déposer le fichier dans le thème enfant

Renommez le fichier téléchargé en page-accueil-koytcha.php et placez-le à la racine de votre thème enfant. Jamais dans le thème parent : la prochaine mise à jour l'écraserait.

Ajoutez ces quatre lignes tout en haut du fichier, avant le <!doctype html> :

<?php
/* Template Name: Accueil Koytcha 2026 */
?>

C'est cet en-tête, et lui seul, qui fait apparaître le modèle dans WordPress.

b. Affecter le modèle à la page

  1. Créez une page (ou ouvrez la page d'accueil actuelle).
  2. Dans le panneau de droite, section Attributs de page, choisissez Accueil Koytcha 2026.
  3. Publiez, puis regardez le résultat.
Le mieux est de tester sur une page temporaire d'abord — par exemple /nouvelle-accueil/. Vous basculez la vraie page d'accueil seulement une fois que tout est vérifié, dans Réglages → Lecture.

c. Rapatrier les images sur votre serveur

Dans le fichier livré, les images pointent vers previsualisation.automatisationboost.com. Ça fonctionne immédiatement, mais votre site dépend alors d'un serveur qui n'est pas le vôtre. Pour être autonome :

  1. Téléversez les images dans la médiathèque WordPress.
  2. Dans le fichier, remplacez chaque https://previsualisation.automatisationboost.com/koytcha-refonte-v5/assets/ par l'adresse de votre médiathèque (https://koytchaimmo.re/app/uploads/2026/09/ par exemple).

Un « Rechercher / Remplacer » dans un éditeur de texte suffit, c'est la même chaîne partout.

3Le module de recherche

Sur WordPress, ne gardez pas le bloc tel quel — mettez le widget Elementor.

Le fichier livré contient une copie du module qui fonctionne hors WordPress grâce à un React chargé depuis un CDN. Sur votre site, WordPress fournit déjà ce React : insérez simplement le widget Search KTP à l'emplacement prévu, et supprimez du fichier les trois lignes marquées <!-- ORDRE IMPORTANT --> ainsi que le bloc window.wp.element à la fin.

L'emplacement est repérable dans le fichier : cherchez class="boite". C'est le conteneur en verre dépoli du premier écran.

L'habillage aux couleurs de la nouvelle page est porté par les règles CSS commençant par .boite .app. Gardez-les si vous voulez le même rendu sombre ; supprimez-les pour retrouver l'apparence d'origine du module.

4Vérifier avant de basculer

  • Le module de recherche affiche un nombre de résultats et le bouton mène bien aux annonces.
  • Le menu s'ouvre sur téléphone et les sous-menus se déplient.
  • Les cinq réalisations portent le bon nom sous la bonne photo.
  • Le pied de page : 45 rue Alexis de Villeneuve, contact@koytchaimmo.re, pas de samedi.
  • Aucune erreur rouge dans la console du navigateur (touche F12, onglet Console).

5Si quelque chose casse

SymptômeCause la plus probable
Les polices ne sont pas les bonnes Une extension ou le thème charge sa propre feuille de style après la page. Les règles du fichier doivent passer en dernier.
Le module reste vide Le widget Elementor n'est pas placé, ou le shim React a été laissé et entre en conflit avec celui de WordPress. N'en gardez qu'un.
Images absentes Un « Rechercher / Remplacer » incomplet à l'étape 2c. Cherchez previsualisation dans le fichier : il ne doit plus rien rester.
La page déborde à droite sur mobile Un conteneur du thème impose une largeur. Le fichier livré ne déborde pas — c'est l'habillage du thème autour.
